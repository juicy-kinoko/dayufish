## 更新协议（各设备自动抓取）

1. 醒来/每天定时：`curl` 更新源 → 读 `version` 对比本地 `version.txt`
2. 不同 → 下载 `package` → **校验 sha256**（对不上就停）
3. 只替换安全区：`memory/`、脚本、文档
4. **灵魂三文件只校验不覆盖**（`灵魂校验.md` 对不上就停手问老大）
5. 绝不自动动：`.env`、`private/`、`profiles/`

## 发布纪律

- 公开仓库**不含** `.env`、`private/`（已在 `.gitignore` 锁死）
- 送人版 = 复制目录 → 删 `.env` 和 `private/` → 填自己的 key
- 私用版 = 含 key，只放自己设备
- 每次发版：改 `version.txt` + `updates.json`（版本、时间、变更、sha256）
- 封装（打 tar/zip）等老大说"封装"再做
