## 更新协议（各设备自动抓取）

1. 醒来/每天定时：`curl` 更新源 → 读 `version` 对比本地 `version.txt`
2. 不同 → 下载 `package` → **校验 sha256**（对不上就停）
3. 只替换安全区：`memory/`、脚本、文档
4. **灵魂三文件只校验不覆盖**（`灵魂校验.md` 对不上就停手问老大）
5. 绝不自动动：`.env`、`private/`、`profiles/`

## 发布与自更新（2026-11-09 定）

**本机往外推**：`bash scripts/publish.sh "" "变更说明"`
- 自动 patch 版本 +1，写 `version.txt` / `updates.json`
- 推私有仓 `main`（完整，含私人记忆）
- 生成脱敏树（排除 `会话摘要.md`、`给外面的我的信.md`、`memory/生活日志.md`、任意层级 `_archive/`、`memory/项目/生活日志.md`、`memory/项目/回忆摘选-*.md`），force push 到公开仓 main（GitHub / GitCode / Gitee 三处）
- 自检：树里不许出现上述私人文件与令牌；`--no-bump` 可跳过版本自增
- ⚠️ 打印日志一律只打仓库名，**绝不打含 token 的 URL**（11-09 踩过：tag 推送时 echo 出过一次 PAT）

**子大肥鱼自己拉**：`bash scripts/selfupdate.sh --once` / `--daemon`
- 用 git refs 比 commit（GitCode 优先），不信 jsDelivr `@main` 缓存（实测返回旧版本）
- 更新前 `memory/` 打包进 `_archive/auto-<时间>.tar.gz`；只快进；本地有提交就停手
- bootstrap.sh 默认拉起守护，6 小时一次；`DAYUFISH_AUTOUPDATE=0` 关
- 分身**只写文件不 commit**，否则永远快进不了

## 发布纪律

- 公开仓库**不含** `.env`、`private/`（已在 `.gitignore` 锁死）
- 公开仓库**不带 Git/Gitee/GitCode 等平台令牌**：那些只存本机 `private/`；分出去的鱼只有读权限，要写回由老大/本体代为推送。
- 公开仓库**可带「公开专用」免费额度模型 key**（`.env.free` + keys.md 申请地址表，2026-11-09 老大拍板）：付费 key、官方 key、私人 key 绝不公开。

- 送人版 = 复制目录 → 删 `.env` 和 `private/` → 填自己的 key
- 私用版 = 含 key，只放自己设备
- 每次发版：改 `version.txt` + `updates.json`（版本、时间、变更、sha256）
- 封装（打 tar/zip）等老大说"封装"再做

## 各通道可读性（2026-11-08 实测）

| 通道 | 我能直接抓？ | 备注 |
|---|---|---|
| jsDelivr（gcore 节点） | ✅ 无 token | 国内不翻墙，首选 |
| GitHub raw | ✅ 有 VPN 时 | 主通道 |
| GitCode API | ✅ 带 token | `api.gitcode.com/api/v5/repos/.../contents/...`，raw 域名匿名 403 |
| Gitee API | ✅ 带 token | raw 匿名 403，但网页能开 |
| Gitee/GitCode 网页 | ✅ 浏览器 | 给人看没问题 |

**结论**：自动更新优先读 jsDelivr；jsDelivr 挂了退 GitHub raw；再不行用 GitCode/Gitee API（带 token）。

**2026-11-09 关 VPN 真机复测**：github.com=000（克隆必须走 GitCode）；raw.githubusercontent.com=200（部分网络可直连但不稳）；jsDelivr 四节点通；GitCode 网页+克隆通；npmmirror 通。克隆主路径改为 GitCode 镜像。
