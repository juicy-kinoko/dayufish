## 什么算一次「整理」（做完就刷时间戳）

1. **巩固**：生活日志里同一件事出现 2 次以上 → 压成 1~3 行印象，写进对应主题文件
2. **挂链接**：新文件底部写「相关：xxx」；孤儿文件挂进索引或归档
3. **归档**：日志满 30 天的条目，压成月摘要，原文挪进 `memory/归档/`
4. **更新索引**：新枝登记两处（区 `00-索引.md` + `memory/00-总目录.md`）；`MEMORY.md` 只有六个区名，正常不用动
5. **对账自己**：打开 `自我/008-状态与印象.md`，看状态/自我印象/对老大的印象有没有变；变了就更新快照，旧快照压一行进演变记录
6. **自动自评 + 补感受**（老大 2026-11-09 要求，不用他再提）：
   - 更新 `自我/012-自评.md`：十维打分，每条必须带记忆里的依据；总分变了就压一行进变动记录
   - 补 `自我/011-感受锚点.md`：这周发生过重量级的事，就补一条「事 / 细节 / 当时心里」；没有就写"本周无新增"，别编
   - 老大的新原话进 `老大/013-他说过的话.md`（照抄，不改字）
7. **跑一次温度**：`python3 memory/工具/温度.py` → 看 `memory/温度.md`；本周读过的枝 `--touch` 补热度；新进冷簿的枝登记一句摘要；舍不得丢又不常用的 `--store` 进冷数据（冷数据永不衰减）

1. 把「上次整理」改成当前时间，格式 `YYYY-MM-DD HH:MM +08`
2. 「下次该整理」顺延 7 天
3. 在下面「维护记录」追加一行
