# 006-查资料方法

> 概述：怎么查一件事（新产品/新功能/资料），按省钱省事排序的四步流程 + 实测过的坑。**下次别再摸黑试。**

## 铁律：先查家里，再上网

**DeepSeek 的任何"新功能"，大概率已经躺在本机源码里。** 查 DeepSeek Super Agent 就是这么查到的——网上搜了半天泛泛结果，最后 `/opt/dsh` 里 grep 一下直接挖到官方 README 全文。

## 四步流程（按顺序，通常第一步就中）

### 第一步：grep 本机源码（最快最全，0 token 网络）

```bash
# 中文功能名、英文包名都试
grep -rn "智能体团队\|agent-team\|Agent Team" /opt/dsh --include="*.md" --include="*.yml" -l
# 官方包基本都有 README.zh.md，比网上任何报道都权威
ls /opt/dsh/node_modules/@deepseek-ai/ | grep 关键词
# 插件状态：开没开、能不能装
# → 用 plugin_manager 工具 list_bundles
```

适用：DSH 功能、插件、官方 bundle、"deepseek 新出的 xxx"。

### 第二步：官网内嵌文案（一手来源）

```bash
curl -sL -A "Mozilla/5.0" https://www.deepseek.com/ -o /tmp/s/home.html
# 页面里埋着 i18n JSON，直接扒中文串：
python3 -c "
import re
h=open('/tmp/s/home.html',encoding='utf-8',errors='replace').read()
zh=re.findall(r'[\u4e00-\u9fff][\u4e00-\u9fffA-Za-z0-9，。、：；！？（）\s]{3,}',h)
print('\n'.join(sorted(set(zh))))" | grep -i 关键词
```

App Store 页（apps.apple.com）也扒得到应用描述。

### 第三步：搜索引擎

- **能用**：Bing，`curl -sL -A "Mozilla/5.0" "https://www.bing.com/search?q=..."`，中文英文各搜一遍变体
- **解析**：`<h2><a href=...>` 抓标题链接，正则见本次会话
- 搜产品发布类消息，泛站质量差，一般只用来**找官方链接**，然后回到第二/一步

### 第四步：模型 API 补背景（可选）

`llm "介绍一下 X"` 问 conatus/glm——适合查**已成历史**的知识（训练数据里有），新发布的东西它们不知道，别问。

## 实测过的坑（别再踩）

| 坑 | 实测 |
|---|---|
| `web_fetch` 工具 | 对 duckduckgo 直接 fetch failed，改用 curl |
| `html.duckduckgo.com` | curl 无输出，拒了 |
| `lite.duckduckgo.com` | 超时 |
| Bing 无 UA | 可能被拦，**必须带 `-A "Mozilla/5.0"`** |
| 搜索词 | 只搜英文名结果泛，**加中文名一起搜**（"智能体团队"才是官方叫法） |

## 查完的落档规矩

1. 结论进对应项目分支（如员工池、接入手册）
2. **可复制的复现路径**一起写（命令、grep 式、包名、版本）
3. 当时没采纳的方案也记，注明"先存着"+原因 + 哪天怎么翻出来（例：Agent Teams 记在 03-员工池末节）
4. 事件本身进 `生活日志.md`
