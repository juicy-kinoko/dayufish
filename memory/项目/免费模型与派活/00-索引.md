# 00-索引：免费模型与派活

> 概述：这一支管两件事——**有哪些免费渠道**、**怎么把活派给它们**。整包可以直接复制到别处使用。

## 这一支里有什么

| 文件 | 讲什么 | 什么时候读 |
|---|---|---|
| `01-接入手册.md` | 9 个渠道的完整配置：baseURL、refs、provider 段、报错对照、验 key 命令 | 要新接一个渠道、或渠道报错 |
| `02-外包与派活.md` | 值不值得派、分型、干跑、质量阶梯、踩过的坑 | 决定要不要派活之前 |
| `03-员工池.md` | 员工名单、**能力分(cap)**、速度、并发上限、实测脾气 | 派活时查参数 |
| `04-模型守卫.md` | 通道挂了自动换道的插件：版本演进、inject 根因、参数、运维流程 | 主模型报错/要改守卫时 |
| `_archive/` | 旧版本原文，**不删只挪** | 想翻旧结论时 |

## 三条一句话结论（不看长文也能用）

1. **免 key 就能用的只有两家**：`OVHcloud`（2 RPM）和 `Kilo`（只限 `:free` 模型）。
2. **baseURL 只填到 `/v1` 或 `/v4`**，SDK 自己补 `/chat/completions`，填全了必 404。
3. **派活靠技能** `~/.dsh/skills/worker-team/`：`llm` 单发、`team.py` 批量（`-p` 分型、`--plan` 干跑、`--stats` 看战绩）。
4. **能力 ≠ 速度**：cap 100 的只有 `flint`/`conatus`/`nemotron`；`glm`/`kilo` 83 中文长文缩水；`dots`/`kilo-code` 67 只配机械活。
5. **conatus 是主力**（日额度大），但**并发只能 2**。

## 复制到别处时

带走三样就够跑起来：

1. 本目录四个文件（知识）
2. `~/.dsh/skills/worker-team/`（工具：`routes.json` + `bin/llm` + `bin/team.py` + `SKILL.md`）
3. 凭据：`private/credentials.yaml` 里的 key（⚠️ 外发前删掉 `private/`，换成自己的）

装上之后改 `routes.json` 里的 `ref` 指向你自己的 key 名，就能开工。
