## 一、五步走完

1. 装 DSH Desktop（官网 `https://www.dshdesktop.cn/dsh/`，或 GitHub Releases 的 v2.0.18 稳定版）。装完必须**启动成功过一次**（生成 `~/.dsh`）。
2. **托盘右键 → 退出**（关窗口不算！）。
3. 备份两个文件（各复制一份改名 `.bak`）：
   - `~/.dsh/.credentials.yaml`
   - `~/.dsh/profiles/desktop/cordis.patch.yml`
4. 改这两个文件（key 段 + provider 段，见下）。
5. 重新打开 DSH → 新建会话 → 模型选择器看分组 → 每家发一句"你好"。

路径：Windows `C:\Users\<用户名>\.dsh\`；macOS/Linux `~/.dsh/`

> **懒人通道**：不想注册任何平台，只填下面「免 key 两家」即可跑通。
> Kilo（不写 `apiKeyEnv`）+ Pollinations（key 固定 `sk-pollinations-free`）。

## 二、.credentials.yaml：refs 段

找到 `refs:` 这一行，在它**下面**按同样缩进（两个空格）加。冒号后留一个空格。

```yaml
  refs:
    ZHIPU_FREE_API_KEY: <智谱 key，形如 xxxxxxxx.xxxxxxxx>
    AMD_API_KEY: <AMD key，形如 rc-xxxxxxxx>
    SENSNOVA_API_KEY: <商汤 key，形如 sk-xxxxxxxx>
    DOTS_API_KEY: <dots key，形如 ak_xxxxxxxx>
    INTERNLM_API_KEY: <浦语 key，形如 sk-xxxxxxxx>
    NIUDS_API_KEY: <牛DS key，形如 sk-xxxxxxxx>
    QINIU_API_KEY: <七牛云 key，必须带 sk- 前缀>
    POLLINATIONS_API_KEY: sk-pollinations-free
```

**领 key 入口**

| 家 | 地址 | 备注 |
|---|---|---|
| 智谱 | open.bigmodel.cn | `glm-4-flash` / `glm-4.5-flash` 免费，**最稳主力** |
| AMD | developer.amd.com.cn/radeon/tokenfactory | `rc-` 开头，送免费积分，**模型最全** |
| 商汤 | platform.sensenova.cn/login | 限额约 2 次/分 |
| dots | dots.ai/platform/login | `ak_` 开头，带工具调用 |
| 浦语 | internlm.intern-ai.org.cn | 每月额度，Intern-S2 |

| Pollinations | 免注册 | key 填 `sk-pollinations-free` |
| 牛DS / 七牛云 | qnaigc 网关 | key 由发放人给；64 位十六进制要自己补 `sk-` |

## 四、报错对照表（先看这张）

| 现象 | 原因 | 修法 |
|---|---|---|
| MISSING_CREDENTIAL / 缺少凭据 | key 没填、`apiKeyEnv` 名字不一致、或没重启 | 名字逐字对齐，托盘退出重开 |
| 401 | key 无效 / 复制漏字 / 七牛云忘 `sk-` | 重贴 key，补前缀 |
| 429 | 限流（商汤 2 次/分、Pollinations 45 秒/次、七牛云常 429） | 等一会儿或换一家，不是配置坏了 |
| 400 / 404 model not found | 模型 id 或 baseURL 写错（大小写敏感） | AMD 用 `DeepSeek-V4-Flash`，不是带 `-0731` 的 |
| 启动崩 | YAML 用了 Tab / 缩进不齐 | 改回空格，`.bak` 覆盖回去 |
| 改了没反应 | 只关窗口没退出 | 托盘右键 → 退出 → 重开 |
| 分组不出现 | provider 配到了别的 profile | 确认改的是 `profiles/desktop/` |

日志：`%APPDATA%\DSH Desktop\logs\host\dsh-<日期>.log`，搜 `llm-pi-ai` 看凭据报错。

## 六、实测判断（我的结论）

- **能当主力的只有两家**：智谱 GLM-4-Flash（快、稳、免费）、AMD Radeon Cloud（模型最全，上下 1M）。
- **其余当回退**：商汤、Pollinations、七牛云限流太紧；浦语按月配额；dots 适合工具调用短任务。
- **Kilo 免 key 但上游可能记录 prompt**，别放敏感内容。
- **9 家全配 ≠ 9 家可用**，配 3 家（智谱 + AMD + Kilo）就够日常，其余留作 429 时的备胎。

### 三条硬规则

1. **baseURL 只填到 `/v4` 或 `/v1`**。`openai-completions` 协议下 SDK 自己补 `/chat/completions`，填全了会变成 `.../chat/completions/chat/completions` → 404。老大那三处错就错在这。
2. **`a55b:free` ≠ `a55b0-free`**：Kilo 用冒号且免 key；qnaigc 用带 0 的，存在但上游 502。
3. 改完必须 `dsh --profile web --dump-config` 验一遍，**退出码 0 才算数**，别只看文件长得对。

### 两家免 key 的底细

- **OVHcloud**：完全不要 key，匿名 2 RPM，131K 上下文。gpt-oss-120b、Qwen3.8-27B、Llama-3.3-70B、Mistral-Small-3.2 都能打。
- **Kilo**：383 个模型里 **10 个带 `:free`**。付费模型返回 `PAID_MODEL_AUTH_REQUIRED`，要登录。`kilo-auto/free` 是自动路由。
