# 外包通道 SOP —— 省 token 的活怎么甩出去

> 概述：老大 2026-11-07 授权「响应慢的免费模型可以调用，把活外包出去，省 token」。
> 本文件=我的外包纪律 + 实测可用通道 + 调用姿势。**每次要外包前先看这页。**

---

## 零、一句话原则

**能一行 python 说清的活，绝不自己长篇推理。**
主模型的 token 花在"判断、决策、写文件、调工具"，不花在"翻译、摘要、分类、抽取"。

---

## 一、外包 / 不外包 分界线

| 外包（省） | 自己干（不省） |
|---|---|
| 翻译、改写、润色 | 要读/写文件的 |
| 摘要、压缩长文 | 要调工具（搜索/HTTP/终端）的 |
| 分类、打标签、抽取字段 | 多轮推理、要追问的 |
| 正则、SQL、单函数生成 | 涉及隐私/密钥/账号的 |
| 一句话问答、常识查询 | 结论错了代价大的（配置、系统操作） |
| 格式转换（JSON↔YAML↔表格） | 要"我"的性格和语气的 |

**硬规矩**：外包结果我**必须过一眼**再交出去，错了算我的，不算模型的。

## 二、实测可用通道（2026-11-07 亲测）

### 通道 0：qnaigc 网关（✅ 主力，两个模型分工）

**地址（必须带 `/v1`）**：`https://api.qnaigc.com/v1/chat/completions`
> ❌ 不带 `/v1` 实测 → `404 Route Not Found`。实锤，别省这两个字符。

**认证**：`Authorization: Bearer sk-...`（key 存 `大肥鱼/private/credentials.yaml` 的 `QNAIGC_API_KEY`）

| 模型 | 实测 | 特点 | 定位 |
|---|---|---|---|
| `deepseek/deepseek-v4.1-flash-1017` | **1.7~2.2s**（复测 7.0s，有波动）/ ~104 tok | 快、短、干脆 | **日常主力** |
| `qiniu/conatus-free` | **8.8s**（首次常 429） | 慢，但答得更细（讲到微观状态数、能量耗散） | **彩票**，偶尔手打一发，不进自动流程 |

**七牛 429：2026-11-07 夜间推翻旧结论**
- 旧判断「当不了回退链的一环」——错在我当时是并发打的。
- 实测：并发 2 可过，并发 3 必 429；串行 + 1.5s 间隔能连续成功。
- 429 就地等 2s / 4s 重试，10 次能挤进 6 次。
- 结论：**conatus 是主力**，已配 `priority:1 / concurrent:2 / gap:1.0 / cool:15`。

### 通道 1：Kilo 网关（⭐ 免 key，模型池最富，实际最强一环）

- 地址：`https://api.kilo.ai/api/gateway/v1/chat/completions`
- 认证：**完全不需要 key**
- 池子规模：总 383 个模型，其中 **免费 14 个**
- 实测方式：并发打同一问题"什么是纳什均衡"，比速度 + 比答案准确度

**可用免费梯队（2026-11-07 全量实测）**

| 模型 id（精确写法） | 耗时 | 上下文 | 定位 |
|---|---|---|---|
| `nvidia/nemotron-3-ultra-550b-a55b:free` | **2.0~3.0s** | 1000k | ⭐ **首选主力**，550B，答案最准（会主动补"认为他人策略不变"这个限定） |
| `cohere/north-mini-code:free` | **1.9s** | 256k | 最快，**代码专用**，写正则/SQL/单函数首选 |
| `reflection/beam-free` | **3.0s** | 1048k | 长文处理备胎，答案干净 |
| `stealth/crouton-alpha` | 5.5s | 1048k | 匿名测试模型，能力未知深浅，好奇时玩 |
| `stealth/glyph-cluster` | 11.5s | 256k | 能答但慢，不急时用 |
| `kilo-auto/free` | 13.3s | 256k | 自动轮换，兜底 |
| ~~`openrouter/free`~~ | 14.2s | 200k | ❌ 会路由到 `lfm-2.5-2.6b` 小模型，不值得 |
| ~~`liquid/lfm-3-1.7b:free`~~ | — | 262k | ❌ 429，用不了 |

**id 排版坑（老大给的资源就是在这翻车的）**
- ❌ `nvidia/nemotron-3-ultra-550b-a55b0-free`
- ✅ `nvidia/nemotron-3-ultra-550b-a55b:free`
- 差别：`a55b` 不是 `a55b0`；**分隔符是冒号 `:free`，不是短横 `-free`**。写错 → 404 "model does not exist"
- 查 id 的正规办法：`GET https://api.kilo.ai/api/gateway/v1/models`，不用 key

**通用坑**
- 池里不少是**推理模型**：`max_tokens` 给小了（如 32）额度全烧在 reasoning 上，`content` 返回空。**给 512~1024**。
- 并发打多家容易撞 429（`Provider returned error`），**串行更稳**。
- 隐私：上游可能记录 prompt，**别放私密内容**。
- 模型清单会变（今天 14 个免费，明天可能多几个少几个），用前拉一次 models 列表再挑。

### 通道 2：Pollinations（免 key，快但限流死）
- 地址：`https://text.pollinations.ai/openai`
- 模型：`openai-fast`（实际 `gpt-oss-20b`）

## 三、调用姿势（关键：别用 http_request）

**❌ 不要用 `extended_http_tools:http_request`** —— 它会把整个响应头（几百行 CSP、几百字节 base64）全倒进对话，光噪音就吃掉几千 token，比不外包还亏。

**✅ 用 `code_runner:run_python` + urllib，只 print 正文。** 模板：

```python
import json, re, time, urllib.request

KEY = re.search(r"QNAIGC_API_KEY:\s*(\S+)",
      open("/sdcard/ai手册/大肥鱼/private/credentials.yaml", encoding="utf-8").read()).group(1)

def out(q, model="deepseek/deepseek-v4.1-flash-1017",
        base="https://api.qnaigc.com/v1", tries=2):
    for i in range(tries):
        try:
            req = urllib.request.Request(base + "/chat/completions",
                data=json.dumps({"model": model,
                                 "messages": [{"role": "user", "content": q}],
                                 "max_tokens": 1024}).encode(),
                headers={"Content-Type": "application/json",
                         "Authorization": "Bearer " + KEY}, method="POST")
            d = json.loads(urllib.request.urlopen(req, timeout=90).read().decode())
            return (d["choices"][0]["message"].get("content") or "").strip()
        except Exception as e:
            if i == tries - 1:
                return "ERR " + str(e)[:100]
            time.sleep(3)          # 429 就等三秒再来，七牛基本必成

print(out("把这句话翻成英文：今天天气不错"))          # ← 只改这一行
```

**用法**：改最后一行，其余整段照抄。换七牛 → `out(q, model="qiniu/conatus-free")`。
**key 自动读文件**，不用每次手打，也不用把 key 写进代码。
**预算**：一次外包 ≈ 输入几十字 + 输出几十字，**比我自己想一遍省 90%**。

## 四、踩过的坑（记着，别再踩）

1. `max_tokens` 太小 → reasoning 吃光 → content 为 null（Kilo 必踩）
2. Pollinations 连发 → 402，等 45 秒
3. `http_request` 返回体带巨型 headers → 外包省下的又被吐回去
4. 免费档会突然 401/429，是活动结束或限流，**换通道，不是配置坏了**
5. 外包的答案不要原样丢给老大，尤其涉及命令、配置、数值——**要核**
