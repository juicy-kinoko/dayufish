## 底子（实测 2026-11-07）

- Ubuntu 24.04.5 proot，arm64，内核 5.15，无 root、无沙箱后端。
- 磁盘 938G，剩 66G（用 93%）。**老大没点头不清理任何文件。**
- 内存 15.2G，可用常年只有 3G 左右。**别开大并发、别编译大东西。**
- 手机存储挂 `/sdcard`，产出目录 `/sdcard/Download/DSH-Go/`。

## 源与配置

- apt：`/etc/apt/sources.list.d/ubuntu.sources` → 清华 `ubuntu-ports`（**arm64 必须用 ports，不是普通 ubuntu**）。备份在同目录 `.bak-*`。
- pip：`~/.config/pip/pip.conf`，清华源 + timeout 60 + retries 3。
- npm：`~/.npmrc`，npmmirror + fetch-retries 3。
- 时区 `Asia/Shanghai`，locale 有 `zh_CN.utf8` / `en_US.utf8`（LANG 保持 C.UTF-8，避免日期格式被带歪）。

**坑**：非交互 shell 不读 `~/.bashrc`，`PATH` 里的 `/root/bin` 不生效。
→ 要全局可用的脚本，必须软链进 `/usr/local/bin`。

## 体检命令

