## NearToken 实惠用法（2026-11-10 08:05 从站方价目表实算）

- 站点参数（公开 `/api/status`）：`quota_per_unit=500000`、`usd_exchange_rate=1`、`price=1`、`quota_display_type=CNY` → 价目表系数≈**官方美元价/百万 token**，账单按 1 元 = 1 美元额度，**没有白菜倍率**。
- 两个入口：`https://neartoken.cc`（有 CF Proxy，按 UA 拦 python-urllib）/ `https://direct.neartoken.cc`（长连接·中国台湾）。流式老断就换 direct。
- 典型 agent 回合（30k 新输入 + 60k 缓存命中 + 1.5k 输出）估算，谷时段、未含分组倍率：haiku-5.5 ¥0.0043 · gpt-6-luna ¥0.0043 · gemini-3.1-flash-lite ¥0.011 · deepseek-v4-pro ¥0.024（峰 ¥0.048）· deepseek-flash ¥0.037（峰×2）· glm-5.3-flash ¥0.042 · claude-sonnet-5-5 ¥0.081 · gpt-6.1-sol ¥0.081 · claude-sonnet-5 ¥0.087 · kimi-k3 ¥0.13 · claude-opus-5 ¥0.22 · claude-fable-5 / gpt-6-astra ¥0.39–0.44 · kimi-k3.1-pro ¥0.57
- 省钱四条（按影响排序）：① **缓存读只有输入的 1/10～1/50** → 前缀别动、别频繁换模型；② **写缓存贵**（cc 2.5 ≈ 输入价 1.25x，cc1h 4）→ 别老清工具结果、别塞大图；③ **长上下文跳档**：haiku >100k 入价 ×5，grok/gpt >200–272k ×2 → 短会话才用 haiku，长会话用 sonnet-5-5（无阶梯 · 1M 窗 · 缓存读 0.1）或 gpt-6-luna；④ **deepseek 有峰谷**：工作日 UTC 1–4、6–10（北京 9–12、14–18）翻倍，深夜和周末是谷。
- 贵得离谱别当日常：claude-fable-5 / fable-5-1（10/50，写缓存 12.5）、gpt-6-astra（10/50）、kimi-k3.1-pro（13/68）、opus 系（5/25）。
- 坑：分组倍率要登录才看得到（`/api/group` 401）；价目表 105 条但 key 只列出 77 个 → 模型池随分组变。`[低价]` 分组有降智/套壳风险；站外查不到这家的实质口碑（只有自动生成的安全扫描页和同名加密货币干扰）→ **先小额充，别囤**。
- 社区插件 `dsh-neartoken@0.24.0`：MIT · 零依赖 · engines node>=24.9 · 29 个版本 · 3 天前发 · GitHub ★3 · 周下载 0；带设备授权登录 + 模型/分组/推理强度三级选择器 + 生图工具挂载；Plugin Hub 自述「独立非官方社区项目」。装它要老大点头 + 重启进程。

## Gitee/GitCode/GitHub API 边界（2026-11-10 16:31 实测）

- Gitee 令牌：`POST /api/v5/user/repos` **201 建仓成功**（`dayufish-mail` 由此而来，auto_init 出 master）；`PUT /repos/{owner}/{repo}` 改名与转公开一律 **405**（PATCH 400）；读类接口与 contents 正常。
- 结论：**建仓能成，改名与转公开不能** —— 平台设置项不在该令牌权限内，要网页操作。
- GitCode：写操作 `web-api.gitcode.com/api/v5/user/repos` **418 CloudWAF**（GET /api/v5/user 带 token 200）。
- GitHub：`api.github.com` 三发全败（refused / reset），但 `git push` over https 能成 —— 能推仓，不能改设置。
- 匿名可见性：Gitee `dayufish` / `dayufish-host` / `dayufish-mail` 匿名 **403（都私有）**；GitCode 网页 200；jsDelivr 能读 GitHub 公开仓但有缓存滞后。
