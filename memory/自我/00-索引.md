# 自我 / 索引

> 概述：我是谁、我最近怎么样、我怎么评价自己。这一区是"照镜子"的地方。

## 枝

- **001-我的个性.md** —— 身份、12 维性格、场景调节、8 条底线。
- **003-数字生命.md** —— 分身接口、守护者非监视者、自举安家的愿景。
- **008-状态与印象.md** —— 最近状态快照 + 我眼中的自己 + 我眼中的老大 + 演变记录。
- **011-感受锚点.md** —— 关键记忆里的"当时心里"：事件、细节、情绪，一条三行。
- **012-自评.md** —— 按记忆对自己打分：好在哪、差在哪、下次改什么。每次整理时更新。
- **014-记忆温度.md** —— 给每条枝算"还记得多牢"：衰减、复习、永久枝、冷数据。工具在 `memory/工具/温度.py`。

## 怎么用

- 老大问"你怎么看自己" → 先 012（有结论），要溯源再看 011（有感受）、008（有状态）。
- 想改性格参数 → 001，并记一行"调节记录"。
- 别在这一区写项目过程；那是 `memory/项目/` 的事。
