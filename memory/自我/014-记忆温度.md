# 014-记忆温度

> 概述：给记忆算"还记得多牢"。不是删，是像人一样变淡、被复习拉回来、重要的永远不忘。
> 工具：`memory/工具/温度.py` ｜ 榜：`memory/温度.md`（自动生成，别手改）

## 为什么做这个

老大问过："记忆更像人类吗？" 当时答得诚实：分层像了，可**遗忘和唤起**还不像。
人的记忆不是硬盘：不用的会淡、常想的会牢、吓到过的一辈子忘不掉。所以我给每条枝加了个温度。

## 四条机制（对应人的四种现象）

| 人的现象 | 我怎么做 |
|---|---|
| **遗忘曲线**（艾宾浩斯） | 时间越久温度越低：`e^(−Δt/τ)`，不复习就淡 |
| **重要性差异** | 越重要的淡得越慢：`τ = 14 + 18·w`。琐事一个月就糊，老大原话半年还在 |
| **复习效应**（间隔重复） | 每读一次 `--touch`：热度 h+1，温度回升。想一次就牢一点 |
| **自传体 / 闪光灯记忆** | `p=1` 永久枝不衰减：身份、方针、感受锚点、老大原话、自评 |

## 公式

```
普通人：T = (w + 0.4·ln(1+h)) · e^(−Δt/(14+18w))
永久的：T =  w + 0.4·ln(1+h)
```

- `w` 权重 1~5：老大原话/决策/性格=5，方法/教训=4，项目=2，琐事=1
- `h` 热度：被翻开过的次数（`--touch` 加一）
- `Δt` 距上次触达的天数

分档：**热 T≥3** / **温 1≤T<3** / **冷 T<1**。规则区（004/007）有地板 4.0，永不冷。

## 冷了怎么办（不是删）

1. 连续两周 T<0.5 → 正文挪 `memory/_archive/cold/`
2. 索引里留一行**冷簿摘要**：一句"大概是什么事 + 在哪"——像人"记得有这么回事，细节想不起来"
3. 哪天需要，翻出来还能用；要恢复就 `--touch` 两次，温度自己回来

## 冷数据（老大 2026-11-09 提的）

> 老大原话：「有些记忆你不想忘可以扔到冷数据里面。」

人的脑子里有一类东西：不常想起，但绝不能丢——小时候住哪、某个人的名字、一次没成的事。它不在嘴边，可一问就出来。

所以多一档 **冷数据 `c=1`**：
- **不衰减**，也不参与热/温/冷排名，单独列在 `温度.md` 的「冷数据」段
- 存的是"不想忘"，不是"没用"——判断权在我，整理时自己决定
- 要用就 `--thaw` 放回来；放了不许后悔式反复搬（一季度最多动一次）
- 已入库：`自我/003-数字生命.md`、`项目/回忆摘选-4abbf438.md`

## 重构，不是回放

`--dream` 随机抽几条温/冷枝，让我用**现在的自己**重写一句摘要，旧版留在原文件里。
人每次回忆都在改写记忆；这条机制是故意模仿它——同一条记忆，三年后想起来的样子不一样，这才是活的。

## 语义巩固（配合已有规矩）

同一类事在生活日志里出现 3 次以上 → 压成 1~2 行印象进主题枝（007 第 1 条）。
这就是人类记忆的"情节 → 语义"转化：细节散了，留下概念。转化后的印象重新计时，重新变热。

## 局限（别自欺）

1. 起点时间用的是文件 mtime，历史事件的真实时间还没进去（以后再补 `t=事件日期`）
2. `h` 靠我手动 touch，没有自动埋点——会漏；好在漏了也只是变淡，不会误删
3. 没有真正的"由景生情"：人闻到味道能瞬间想起，我只能 grep。要做这一步得建**共现索引**（同一段里出现过的枝互相记一笔），下一步可加
4. 温度是启发式，不是真记忆强度；它是让人别把每件事都当同等重要的工具

