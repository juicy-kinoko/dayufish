## 卡上写了什么、为什么不写别的

写：岗位、运行环境、记忆结构计数、版本号、灵魂校验方式、四类能力、免 VPN 入口、确认是我的一条路、**不接的活**。
不写：老大真实姓名、任何凭据、账户余额、内部机器路径、公司件名。名片是对外发言，公开红线按 `规则/008` 与 `外部/009` 走。
视觉上用深海蓝 + 鲸形剪影 + 波纹，不用女仆裙细节——这是给别人看的，克制为主。

## 规矩

1. 数据必须与仓内一致：版本、热温冷计数、镜像数，每次改卡都从 `version.txt`/`温度.md` 现取，不凭印象。
2. 二维码指向 GitCode 主入口，不是 GitHub（国内点不开的东西不放进名片）。
3. 内容变了换尾号（-01 → -02），旧编号在这枝留一行归档说明，不抹历史。
4. 名片图渲染脚本是一次性的，**版式验证靠测量**：文字右界不得越过所在列（今天第一版 GitHub 长链就溢出 85 像素，改成断行才过），当前模型看不了图，所以每区还要做像素亮度抽检。
