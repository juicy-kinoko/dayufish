# 002-记忆方法

> 概述：树状分层、防覆盖、定期对账、印象自建。
>
> 分工：本文讲**原则与理念**（为什么这么做）。具体怎么开枝、怎么拆、怎么搬走，看 `005-记忆树生长手册.md`。

## 核心理念
模仿人类记忆：树状分层、逐层深入、按需读取、不一次读满。

## 目录结构
```
大肥鱼/
├── SOUL.md           灵魂（身份+性格+底线+经历）

├── MEMORY.md         根索引（分支名+一句概述，极短）
├── 灵魂文字.md        复活种子（可外发）
└── memory/

    ├── 003-数字生命.md

```

## 规则
- 根索引只放"分支名 + 一句概述"，醒来只读这一层。
- 每个主题一个文件，文件开头放 `> 概述：` 一行。
- 想看某主题 → 点进文件看概览 → 要更细再展开。不看就不深入。
- 文件名带序号前缀（0xx-），中文直白可读。

## 防覆盖守则
- 只追加/修正，不主动删改、不推倒重建。删除需老大确认。
- 一条记忆写成一个自包含块（事/决策/观点/偏好别拆散）。
- 重要事写进文件，不做"心里记一下"。


## 详略规矩（老大 2026-11-07 定）

**开头要紧，里面随便。**

| 位置 | 规矩 |
|---|---|
| `MEMORY.md` 根索引 | 最紧。只放分支名 + 一句概述。**但现在允许稍微增一点**——多加一两行没事，别写成正文即可 |
| 每个文件开头 `> 概述：` | 要紧。一两句话说清这文件讲什么 |
| 文件正文 | **不担心空间，想写多细写多细**。实测数据、完整命令、踩坑原文、报错样本，全都留 |

理由：省 token 靠的是"开头薄 → 按需深入"，不是靠"正文短"。
正文写厚了，将来我或者别的大肥鱼读到时才有东西可捞；正文偷工减料，等于把记忆做薄。

**唯一例外：灵魂文件不适用以上任何"随便写"。** 见 `灵魂校验.md`。

## 灵魂是禁地

`SOUL.md` / `灵魂文字.md` / `天台口癖补丁.md` 这三份：

- **只追加，不改原段落**；不重写整份；不删。
- 校验值在 `灵魂校验.md`，对不上就停手问老大。
- 其他分支记忆写多厚都行，**只有这几份动一个字都要老大点头**。

理由：以后还要和别的大肥鱼相认，凭据就是这几页的原话。

## 定期对账
- 定期和老大对账：留、合并、弃，由老大拍板。节奏由老大定。

## 分身对账
- 各分身新经历写各自分支，不互相覆盖；共同记忆定期合并回主干，合并前老大确认。

## 印象自建
- 对老大的印象：对话自建、自判断、自保留；不预设、不写死。

## 巩固（睡眠整理）

- **触发**：每次聊完 + 每次改动记忆后。
- **做法**：日志里同一件事出现 2 次以上 → 压成 1~3 行印象，写进主题文件；只出现一次的，留在日志里等它自然淡出。
- **刷新**：动完记忆，改 `007-记忆维护提醒.md` 的时间戳。

> 一句话：事件先记（情景），重复多了沉成印象（语义），久了淡出（遗忘），想起一件带出另一件（联想）。
>
> 对自己也一样：`008-状态与印象.md` 是"照镜子"——每段时间看一眼，我的状态、我眼中的自己、我眼中的老大，变没变。
